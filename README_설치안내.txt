STOCK LAB v3 - 아이콘 폴더 없는 배포판

GitHub 저장소 최상위 위치에 이 ZIP의 파일을 모두 업로드하세요.
icons 폴더를 만들 필요가 없습니다. icon-192.png와 icon-512.png는 다른 파일과 같은 위치에 있어야 합니다.

중요: 기존 GitHub에 파일이 남아 있으면 동일 경로 파일을 교체해야 합니다. 파일명 뒤에 (1) 등이 붙지 않도록 확인하세요.

Render 배포 후 다음 주소들이 정상 열리는지 확인:
/manifest.webmanifest
/icon-192.png
/icon-512.png
/sw.js

Chrome에서 사이트를 열고 홈 화면에 추가 > 설치를 확인하세요. 설치가 비활성화되면 Chrome 사이트 데이터 삭제 또는 새 탭에서 다시 접속 후 확인하세요. 브라우저 정책에 따라 바로가기만 제공될 수 있습니다.

주의: 이 수정은 PWA 아이콘 경로와 설치 관련 설정만 수정했습니다. 금융 데이터 제공 API 연결 여부와 무관하며, 자동 분석 기능을 추가하거나 보장하지 않습니다.
